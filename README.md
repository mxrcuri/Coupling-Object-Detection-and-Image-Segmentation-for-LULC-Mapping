# High-Resolution LULC Classification: YOLOv8 + Segment Anything Model (SAM)

## 📌 Project Overview

This repository contains the codebase and methodology for an advanced Land Use and Land Cover (LULC) classification pipeline, developed during a research internship at the **Regional Remote Sensing Centre - North (RRSC), NRSC, ISRO**.

Traditional pixel-based classification struggles with high-resolution imagery due to increased heterogeneity and mixed pixels. To address this, we implemented a novel **object-based classification approach** on 0.45m resolution Cartosat-3 satellite imagery.

This pipeline integrates **YOLOv8** for precise object detection (bounding box generation) and Meta AI's **Segment Anything Model (SAM)** for zero-shot instance segmentation.

## 🚀 Key Features

  * **Two-Stage Pipeline:** Utilizes YOLOv8 as a precursor to segmentation, providing highly accurate bounding-box prompts to SAM.
  * **High-Resolution Processing:** Optimized for 0.45m Cartosat-3 imagery across highly clustered and unorganized urban/semi-urban areas in Delhi.
  * **Geospatial Export:** Segmented masks are automatically processed, georeferenced, and exported as vector `GeoPackage` files for seamless integration into GIS software.

## 📊 Dataset Preparation

Because public datasets like xView lacked the specific classes required for Indian urban LULC mapping, a custom dataset was developed:

  * **Source:** Cartosat-3 GeoTIFF tiles sliced into 1280x1280 patches.
  * **Classes:** Building, Agriculture & Grassland, Bare Ground/Vacant Plot, and Aircraft.
  * **Augmentation:** Expanded the dataset 5x (to 620 images) using the `Albumentations` library, applying Rotation, Flip, Crop, and RGB Shift to improve model robustness.

## 🧠 Methodology & Architecture

### 1. Object Detection (YOLOv8l)

We utilized the YOLOv8 large variant (43.6M parameters) to detect discrete objects and generate bounding boxes.

  * **Optimizer & Losses:** Trained using the Adam optimizer. The loss function minimizes CIoU and DFL for high localization accuracy (especially for small targets) and Varifocal Loss (VFL) to handle severe class imbalances.
  * **Training Hardware:** NVIDIA A100 GPU.
  * **Hyperparameters:** `epochs`: 175, `batch`: 8, `imgsz`: 640, `lr0`: 0.001.

### 2. Image Segmentation (SAM)

The bounding boxes generated by YOLOv8 are fed into SAM (ViT-H/16 architecture) as box prompts via the `SamPredictor` interface.

  * **Fine-Tuned Parameters for Dense Areas:**
      * `pred_iou_thresh`: 0.5
      * `stability_score_thresh`: 0.75
      * `box_nms_thresh`: 0.7 (crucial for handling closely packed objects like slum housing)
      * `min_mask_area`: 15 pixels

## 📈 Performance Metrics

The YOLOv8 detection model achieved the following performance metrics at a confidence threshold of 0.25:

| Metric | Score |
| :--- | :--- |
| **Precision** | 0.86 |
| **Recall** | 0.74 |
| **F-1 Score** | 0.785 |
| **mAP@50 (All Classes)** | 0.792 |

**Class-specific mAP@50:**

  * Planes: 0.985
  * Agriculture & Grassland: 0.805
  * Bare Ground/Vacant Plots: 0.778
  * Built-up: 0.602

*Note: This object-based pipeline is highly effective for discrete features (buildings, plots) but is not designed for continuous LULC features like rivers and road networks.*
